Revenue Strategy

  • Diagnostic — cash-flow entry point. Low resistance, immediate revenue. Priced $149–$499.
  • Battery Retrofit — primary profit driver. One close = $3,299 to company.
  • Monitoring + Panel Cleaning — recurring revenue. 100 active accounts = $1,579/mo passive income. Cleaning 2×/year included; cost absorbed into company margin to keep price competitive at $49.99/mo.
  • Partner / Add-On Leads — leads outside current scope (roofing, HVAC, EV charging, new installs for unqualified customers) can be sold or closed through vetted partners, increasing revenue per customer without adding operational overhead.
  • Future Partnerships — retail distribution through Sunly or Lowe’s directly, expanding reach into high-traffic retail channels without direct marketing spend.
  • Key lever: Improving diagnostic-to-retrofit conversion from 20% → 35% roughly doubles revenue without a single new lead.

5 — Go-to-Market Strategy
Phase 1 — Now → Month 3
Goal: 10–20 diagnostics/month · 2–4 battery retrofits/month
  • Field outreach — Sales team knocks doors in high solar-density neighborhoods. Target homes with visible panels in Chula Vista, El Cajon, Santee, Poway, Escondido.
  • Referral seeding — every completed diagnostic = ask for 2 referrals.
  • GHL follow-up automation — every booked eval gets automated reminders. Every no-close gets a 30/60/90-day nurture sequence.
  • Google Business Profile — fully optimized with photos, services, and active review responses.
Phase 2 — Month 2 → Month 6
Goal: 30–50 diagnostics/month · 8–12 retrofits/month
  • Google Local Services Ads (LSA) — "Solar inspection San Diego," "solar battery backup," "solar not working." Pay per lead, not per click. Highest ROI for a local service business.
  • SEO landing pages — /solar-diagnostic-san-diego, /battery-backup-installation, /powerwall-installer-san-diego targeting high-intent keyword clusters.
  • Facebook / Instagram — before/after content, educational reels (why solar systems degrade), testimonials. Retarget site visitors with offer ads.
Phase 3 — Month 6+
Goal: $50K+/month revenue · multiple reps · expand to LA/OC
  • Hire 2–3 additional field setters.
  • Launch monitoring subscription service (panel cleaning included).
  • Explore solar financing partnerships to increase battery retrofit close rate.
  • Expand to LA and Orange County with local ops partners.
  • Pursue retail partnerships — Sunly and/or Lowe’s as direct retail distribution channels.

↓
Phase 0 — AI Lead Scoring
Score all new leads before enrichment
  • Input: installer name, install year, system size (kW), ZIP code
  • Model: Claude claude-sonnet-4-6 — classifies urgency (high/medium/low) from permit metadata
  • Output: lead_score 1–100 stored per record; high scores surface first in canvassing queue
  • Fallback: Deterministic scoring (install age + system size + ZIP density) when key not set
↓
Phase 1a — Socrata Permit Pull (Saturated)
City of SD + unincorporated county open datasets — already fully harvested
  • Source: data.sandiego.gov (City of SD only) + data.sandiegocounty.gov (unincorporated)
  • Coverage: ~15,728 records — these public datasets are incomplete and all records are already in DB
  • Status: Saturated — 0 new records per run — skipped when PERMITSTACK_KEY set
↓
Phase 1c — PermitStack SD Cities (Primary SD Source)
City-by-city permit pull across all 16 SD incorporated cities — 60–100K expected total
  • Source: PermitStack API — aggregates DSD + all city permit portals that Socrata misses
  • Cities: San Diego, Chula Vista, El Cajon, La Mesa, Santee, Escondido, Poway, Oceanside, Carlsbad, Encinitas, National City, Vista, San Marcos, Lemon Grove, Spring Valley, Lakeside
  • Loop: installer → city → keyword pages (up to 30 × 100 results), real-time insert as found
  • Time budget: 5 minutes per nightly run — multiple nights to exhaust full dataset
  • Status: Active — hundreds to thousands new per run
↓
Phase 1b — PermitStack OC / Riverside (Expansion)
Orange County + Riverside — activates when SD market saturates
  • Gate: Expansion index ≥20 for OC (15 cities); ≥54 for Riverside (Temecula, Murrieta…)
  • Current index: 35 — OC Active Riverside Locked (need ≥54)
  • Time budget: 4 minutes per nightly run
↓
Phase 2 — Owner Enrichment (Regrid + SANDAG)
Parcel owner name + lat/lng for all leads missing it
  • Primary: Regrid parcel API — address search returns owner name + coordinates. Paid, reliable, ~40 req/min.
  • Rate limiting: 1.5s gap between requests; 2-min global pause on 429
  • Fallbacks: Census geocoder → SANDAG ArcGIS spatial parcel lookup → SANDAG Parcels_South
  • Output: title_owner, lat, lng, apn written to Supabase
  • Time budget: 6 min (full run) / 10 min (enrich-only)
  • Backlog: ~14,956 leads need Phase 2. Run enrich-only 8× to flush all.
↓
Phase 3 — Tracerfy Skip-Trace (Phone + Email)
Retrieve phone and email for canvassing follow-up
  • API: Tracerfy batch skip-trace — 1 credit/hit at $0.02 (charged only on successful matches)
  • Filter: address_quality_score ≥ 9, no phone, no email, enrichment_source IS NULL (not previously tried)
  • Priority: Sorted by newest install year first — highest-value homes surface first
  • Per-run cap: 500 (full) / 2,000 (enrich-only) — 21K credits available (~$420)
  • DNC: Tracerfy returns do_not_call flag — pipeline writes dnc=true; canvassing UI hides DNC leads
  • Output: phone, email, enrichment_source='tracerfy', dnc written to Supabase
